# 使用与回退

## 转换入口

主配置：

```text
https://raw.githubusercontent.com/dearjnana/ClashRule/refs/heads/main/profiles/openclash.ini
```

转换请求需带 `target=clash`、`expand=true` 和正确编码的 `config` 地址。订阅地址通过 `url` 参数传入，不要写进公开仓库。

将转换结果保存为 `converted.yaml`，执行：

```sh
python tools/finalize.py converted.yaml ready.yaml
mihomo -t -f ready.yaml
```

通过检查后再导入 OpenClash。DNS、控制器认证和防火墙仍由客户端负责。本仓库不自动登录设备或重启网络。

## 手机入口

Clash Meta for Android 使用 `profiles/android.ini`，OpenClash 使用 `profiles/openclash.ini`。分流列表一致，手机关闭局域网监听，健康检查周期为 900 秒，VPN 和 DNS 接管由应用设置管理。两者均需转换后整理，再导入客户端。

适配依据为 [Clash Meta for Android v2.11.34](https://github.com/MetaCubeX/ClashMetaForAndroid/releases/tag/v2.11.34)，其 Mihomo 子模块版本为 `ab405bad5beeeac8b003bb01f60f134f6df54471`。已核对原生分组字段支持；不声称已经在用户手机上实际运行。

## Gemini

Gemini 与 Google FCM 优先于通用 Google 和 AI 规则。Gemini 默认使用 MESL 美国专用组，名称筛选会排除亚美尼亚、澳大利亚、俄罗斯等误匹配；无匹配节点时为 REJECT，不回落到直连。

节点名称不能证明实际出口地区或 Gemini 可用性。手机应用还受 Google 账号地区、设备 DNS 和账号资格影响。本仓库的测试验证规则匹配和分组，不代表真实账号登录成功。

## 其他客户端

`rules/` 是可独立引用的维护规则；规则条件不携带策略动作，策略由调用者指定。`generated/rules/` 已按主配置顺序跨文件去重，不适合单独移植到不同策略顺序。

[Clash Party 覆写](../clients/clash-party/override.yaml) 保留该客户端的组名和使用方式，并修正 Adobe 放行例外、Pixiv 例外及 Gemini 优先级。不要当作 OpenClash 的服务器配置使用。

## 回退

变更设备前先在设备本地保存当前可用配置。出现连接问题时恢复该配置，不要清空正在运行的订阅。Git 历史用于恢复仓库版本，仓库不额外保留旧原文副本。迁移前的根目录 Raw 地址已经失效，参见 [地址迁移表](根目录迁移链接.md)。
