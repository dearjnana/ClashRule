# 来源与维护

各规则源的地址记录在 [来源清单](../config/sources.json)，文件头同时注明来源。清单仅保存地址，不保存原始文件或原文片段。

- [ACL4SSR](https://github.com/ACL4SSR/ACL4SSR)：多数网络、服务和媒体规则。相关衍生规则沿用 CC BY-SA 4.0，许可证法律正文见 [许可文件](../licenses/ACL4SSR-LICENSE.txt)。
- [blackmatrix7](https://github.com/blackmatrix7/ios_rule_script)：Disney 全家桶规则的原作者。
- [IP 归属地规则](https://github.com/lwd-temp/anti-ip-attribution)：条件列表已移除混入的策略字段，保留 no-resolve 语义。
- 本仓库作者维护的个人出口、广告例外、脚本和补充规则按用途归类。

规则源已经规范化、纠错和去重，文件内容与上游未必相同；来源署名不表示原作者认可这里的修改。上游更新不会自动覆盖本仓库维护内容。

## 维护约定

1. 只编辑 `rules/` 与 `config/`，重新构建生成结果。
2. 域名条件不混入 DIRECT、PROXY 或其他策略动作；IP 条件按需保留 `no-resolve`。
3. 专用服务规则先于通用服务，放行例外先于拦截，兜底 MATCH 放最后。
4. 同策略去重不改变条件覆盖范围；不因名称相近而合并不同策略。
5. 注释和维护文档用中文。英文协议字段、域名、变量名称和许可证正文不翻译。
6. 不提交订阅凭据、后台秘密路径、真实服务器备份或测试输出。

来源与实现文档：[Mihomo 代理组](https://wiki.metacubex.one/config/proxy-groups/)、[Mihomo 规则集合](https://wiki.metacubex.one/config/rule-providers/)、[SubConverter-Extended](https://github.com/Aethersailor/SubConverter-Extended/wiki)。
