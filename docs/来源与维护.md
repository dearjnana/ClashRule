# 来源与维护

本包基于 2026-09-20 下载的 `dearjnana/ClashRule/MyRuleClash_Plus_V1.ini` 及其 44 个实际依赖文件。每个文件的完整地址、下载时间、字节数及 SHA-256 保存在 [manifest.json](../audit/original/manifest.json)。原 INI 单独记录在 [source-metadata.json](../audit/original/source-metadata.json)。

`Gemini.li` 不是此次 INI 中的实际路径；原配置引用的是 `Gemini.list`，已完整下载。优化版引用仓库自己的 `rules/ai/Gemini.list`，可以在自己的仓库维护，不能通过修改本地副本直接改变 ACL4SSR 上游仓库。

## 上游与署名

- [dearjnana/ClashRule](https://github.com/dearjnana/ClashRule)：原 INI 和用户维护的规则；旧路径保留。
- [ACL4SSR/ACL4SSR](https://github.com/ACL4SSR/ACL4SSR)：多数服务、广告、网络规则及原基础模板。上游许可证为 **CC BY-SA 4.0**，全文保存于 [ACL4SSR-LICENSE.txt](../licenses/ACL4SSR-LICENSE.txt)。相应快照及本包衍生修改沿用该许可证，来源标在各规则文件头，修改明细见逐条审计记录。
- IP 归属地规则使用原 INI 指定的上游文件；精确地址保留在 `rules/privacy/IPAttribution.list` 和下载清单中。原作者注释和原始 payload 保存在快照。

上述来源不代表上游认可本包的修改。各来源保留自身许可；本次没有替整个历史仓库重新指定统一许可证。

## 实现依据

- [Mihomo 代理组通用字段](https://wiki.metacubex.one/config/proxy-groups/)：`include-all`、`empty-fallback`、`default-selected`、`lazy`、`expected-status`。
- [Mihomo 规则集合](https://wiki.metacubex.one/config/rule-providers/)：原生 domain / ipcidr 集合。
- [SubConverter-Extended API](https://github.com/Aethersailor/SubConverter-Extended/wiki/API-Reference)：`expand=true`；验证固定使用正式版本 v1.9.6。
- [Google Gemini API](https://ai.google.dev/api/generate-content)：`generativelanguage.googleapis.com`。
- [Google Colab](https://colab.google/)：补充 Colab 的具体服务域名，替代宽泛 `colab` 关键词。
- [ARIN 17.253.4.125 查询](https://rdap.arin.net/registry/ip/17.253.4.125)：该地址归属 Apple 的地址段，原 AI 文件把它标作 Grok 缺少依据。

## 后续更新

本包把外部依赖固定为本地审计快照。上传后不会继续跟随 ACL4SSR 等上游自动变化，减少规则漂移，也意味着需要定期人工同步。更新时应保留新旧清单和 SHA-256、查看变化、重新生成并运行验证；不要直接覆盖 `audit/original` 而丢失本次依据。

可以先独立维护 `rules/ai/Gemini.list` 做小范围调整，但重新运行 `build.py` 会恢复生成结果。正式维护建议把变更写入 `tools/build.py` 的补充规则和正规化逻辑，并配套加入 `tools/verify.py` 的行为样例。

`rules/` 中的去重结果依赖本包 INI 的优先级；不能随意将单个已跨文件去重的规则复制到完全不同的配置后，仍认为它是上游全集。完整上游数据始终在快照中。
