# 规则整改结果

更新日期：2026-09-20。

## 仓库结构

移除原始快照、原始片段、旧 README、空占位文件、重复旧配置和无引用图片。规则统一维护在 `rules/`；策略组、优先级、基础设置位于 `config/`。生成器直接读取这些维护文件，不再依赖原始档案。

51 份规则源中，43 份参与主配置，其余用于独立客户端或个人补充，未擅自全部加入主配置。维护规则与按顺序去重后的输出职责分离，避免修改源文件后被旧快照覆盖。

## 已修正的问题

- Gemini 的网页、应用、AI Studio 服务统一到一个规则文件，排在通用 Google 与 AI 前面。
- 修复 `.oaistatic.com` 错误精确匹配；将 Google 推送和共享 Cloudflare 从 AI 抢占规则中移除。
- Telegram 统一为纯条件列表，不再使用混有 PROXY 动作的 YAML 片段，也不延续未经证实的 `91.108.0.0/16` 宽范围补充。
- Adobe 放行例外及 Pixiv 必要例外优先；同步修正 Clash Party 覆写中的错误顺序。
- 同文件重复、被后缀覆盖的子域名、CIDR 主机位和个人 DNS 列表重复已整理。
- MiniMax 补充规则保留域名后缀，移除过宽关键词。
- 八份旧 INI 统一迁移到当前维护入口，不再保留旧版本副本。

## 性能与验证

主配置为 2,842 条主规则，配合 7,109 条中国 IP 前缀和 4,303 条代理域名；展开版为 14,702 条。80 个策略组保留原生过滤、空组拒绝、按需健康检查和选择记忆。

离线验证覆盖 26,104 个域名场景、33,070 个 IP 边界场景和 18 个服务回归场景，并检查去重前后策略链、IP 解析选项和原生集合覆盖一致。隔离转换测试验证两份输出通过 Mihomo 配置检查，并实际检查 MESL 美国组成员、空组行为和规则集合加载。

隔离转换使用 SubConverter-Extended v1.9.7，配置检查使用 Mihomo v1.19.31。OpenClash、Android 和展开配置均通过；Android 与路由器共用分流规则，基础监听和健康检查周期分别适配。

这些验证不访问真实机场节点，也不代表 Gemini 账号的地区资格或服务可用性。部署与规则整理步骤见 [使用说明](使用与回退.md)。
