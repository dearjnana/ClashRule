# 仓库文件索引

| 目录 | 用途 |
|---|---|
| `rules/` | 唯一维护的规则源，按服务分类 |
| `config/` | 规则顺序、策略组、基础设置和来源地址 |
| `generated/rules/` | 按主配置顺序去重后的生成规则 |
| `providers/` | 原生域名和 IP 规则集合 |
| `profiles/` | 主配置和完全展开配置 |
| `templates/` | 生成的基础模板 |
| `clients/` | Clash Party 等客户端覆写 |
| `scripts/` | Sub-Store 节点脚本 |
| `deploy/` | 容器部署示例和配置说明 |
| `tools/` | 构建、检查和转换后整理工具 |
| `docs/`、`licenses/` | 中文说明和来源许可 |
